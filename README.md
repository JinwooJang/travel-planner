# 오만 로드트립 플래너

두바이에서 출발하는 오만 자동차 여행을 구글 위성지도 위에서 짜는 플래너예요. 서버 없이 `index.html` 파일 하나를 브라우저로 열면 돼요.

## 쓰는 법

1. `index.html`을 크롬이나 엣지로 열어요.
2. 처음 열면 구글 지도 API 키를 넣는 칸이 나와요. 키는 그 브라우저의 저장소(localStorage)에만 저장되고, 파일에는 들어가지 않아요.
   - 구글 클라우드 콘솔에서 켤 API: **Maps JavaScript API**, **Routes API**, **Places API (New)**
   - 키 제한: "API 제한"으로 위 세 개만 허용하고, 할당량이나 예산 알림을 걸어 두세요. 파일(`file://`)로 여는 방식이라 HTTP 리퍼러 제한은 걸 수 없어요. 웹 서버에 올려서 쓴다면 리퍼러 제한도 거세요.
3. 위쪽 탭에서 기본 코스를 보거나 **직접 짜기**로 들어가요.

## 웹에서 열기 (GitHub Pages)

`main`에 `index.html`이 바뀌어 올라가면 `.github/workflows/pages.yml`이 그 파일 하나만 GitHub Pages에 올려요(`src/`, `tools/`, 데이터 원본은 올라가지 않아요).

- 주소: https://jinwoojang.github.io/travel-planner/
- 처음 한 번은 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿔야 해요. 그다음 **Actions → Deploy planner to GitHub Pages → Run workflow**로 한 번 돌리면 돼요.
- 웹 주소로 열면 키 입력 창에 넣을 웹사이트 제한 주소(`https://jinwoojang.github.io/travel-planner/*`)가 나와요. 키를 이 주소로 제한하면 다른 곳에서 키를 쓸 수 없어요. 단, 그 키는 내 컴퓨터에서 파일로 연 플래너에서는 막혀요.
- 브라우저 저장소는 주소마다 따로라서, 파일로 열어 쓰던 플랜은 플랜 파일(.json)로 내보낸 뒤 웹 주소에서 불러와야 해요.
- Pages로 올린 페이지는 저장소가 비공개여도 주소를 아는 사람은 누구나 열 수 있어요. 키는 페이지에 들어 있지 않으니, 다른 사람은 자기 키 없이는 지도를 못 써요.

## 주요 기능

- **기본 코스 5개**: 6일 차로만, 6일 비행 연계, 9일 전체, 6일 샬랄라 집중, 5일 북부. 일차별 시간표, 운영시간·금요일 경고, 구글 길찾기 링크.
- **직접 짜기**
  - 플랜 여러 개 저장, 다른 이름으로 저장, 이름 바꾸기, 삭제. 기본 코스 5개도 플랜으로 들어 있어요.
  - 지도를 **오른쪽 클릭**하면 추가 메뉴가 나와요. 왼쪽 클릭만으로는 추가되지 않아요. 경로 선이나 1시간 표시를 오른쪽 클릭하면 그 구간에 경유지를 넣어요.
  - 지점마다 머무는 시간, 또는 "몇 박 후 몇 시 출발"을 정하면 뒤쪽 시간이 모두 다시 계산돼요.
  - 운전 시간 여유 0~50%: 플랜 전체 일괄 + 구간별 따로.
  - 구간마다 다른 선 색, 겹치는 길은 차선처럼 나란히 갈라져 보여요. 1시간마다 지나는 시각과 km 표시.
  - 날짜별 운전 시간 요약, 하루 8·10시간 초과, 해 진 뒤 운전, 3시간 넘는 연속 운전 경고.
- **관광지 레이어**: 오만 전역 93곳(8개 지역, 7개 종류). 설명, 팁, 권장 체류 시간, 아이와 가기 좋은지, 자료 출처. 카드에서 바로 플랜에 넣을 수 있어요.
- **보기 / 편집 모드**: 위쪽 **보기**를 누르면 지도를 보다가 잘못 눌러도 플랜과 시간이 바뀌지 않아요. 번호 핀 끌기, 추가 메뉴, 삭제·되돌리기, 머무는 시간과 출발 시각 고르기가 모두 잠겨요. 고칠 때는 **편집**을 눌러요. 고른 모드는 그 브라우저에 기억돼요.
- **내 위치**: 지도 위 **내 위치** 버튼을 누르면 폰 GPS로 파란 점과 오차 범위를 보여 주고, 움직이는 중이면 가는 방향도 표시해요. 켜진 상태에서 다시 누르면 내 위치로 지도를 옮기고, ✕로 꺼요. 파란 점을 누르면 그 자리를 플랜에 넣을 수 있어요(편집 모드). https 주소(GitHub Pages)에서만 되고, 위치는 어디에도 저장하지 않아요. 화면이 꺼지거나 다른 앱으로 가면 위치 갱신이 멈춰요.
- **내보내기·불러오기**: AI에 붙여 넣을 텍스트(.txt 저장 또는 복사), 다시 불러올 수 있는 플랜 파일(.json, 계산한 경로 포함). 받은 파일은 "파일 불러오기"나 끌어다 놓기로 추가해요.
- **지도 표시 고르기**: 지도 위 **표시** 버튼에서 지도에 보일 글자를 하나하나 켜고 꺼요. 지점 글자(이름, 시각, 날짜), 1시간마다 지나는 곳(시각, km, 근처 지명), 구간 번호, 관광지 이름. 시각을 끄고 날짜만 켜면 지점마다 날짜만(1박 이상이면 `10/15(목)~10/16(금)`) 보여요. 1시간 표시의 글자를 다 끄면 점도 사라져요. "글자 모두 끄기", "모두 기본값으로"도 있고, 고른 상태는 그 브라우저에 기억돼요. 같은 곳에서 투명도(글자 배경, 경로 선, 관광지 핀)도 조절해요.
- **촘촘한 확대·축소**: 지도 오른쪽 아래 +/− 버튼과 마우스 휠은 기본 ½단계씩 움직이고, 휠은 마우스가 있는 곳을 중심으로 확대해요. 간격은 **표시** 패널에서 1 / ½ / ¼단계 중에 골라요. 폰에서 두 손가락으로 맞춘 크기는 정수 단계로 튕기지 않고 그대로 남아요.
- 24시간제, 날짜 표시, 지도와 패널 사이 경계 조절.

## 데이터가 저장되는 곳

플랜과 설정, 계산한 경로는 브라우저 저장소(`localStorage`의 `omanGmaps.*`)에 있어요. 같은 브라우저에서 같은 위치의 파일을 열어야 보여요. 다른 PC나 브라우저로 옮길 때는 플랜 파일(.json)로 내보내서 불러오세요.

## 구글 API 비용 (2026년 10월 기준, 바뀔 수 있음)

| 쓰이는 곳 | SKU | 월 무료 | 초과 시 |
|---|---|---|---|
| 지도 열기 | Dynamic Maps | 10,000회 | 1,000회당 $7 |
| 구간 경로 계산 | Compute Routes Essentials | 10,000회 | 1,000회당 $5 |
| 구글 장소 이름 | Place Details Pro | 5,000회 | 1,000회당 $17 |
| 확대 후 빈 곳 클릭 시 주변 장소 | Nearby Search Pro | 5,000회 | 1,000회당 $32 |
| 장소 검색창 | Text Search Pro | 5,000회 | 1,000회당 $32 |

계산한 경로와 장소 이름은 브라우저에 저장해 두고 다시 요청하지 않아요.

## 개발

```
index.html                 빌드 결과물 (직접 고치지 말고 src를 고친 뒤 빌드) · GitHub Pages로 배포돼요
.github/workflows/pages.yml  index.html만 Pages에 올리는 워크플로
src/template.html          화면·로직 전체 (__DATA__ 자리에 데이터가 들어가요)
src/data/gdata.json        지점, 일차, 코스, 지명, 내장 도로망 (tools/build*.mjs로 생성)
src/data/pois.json         관광지 93곳 (tools/build_pois.py로 생성)
src/data/pois-research/    지역별 관광지 조사 원본
tools/                     데이터·빌드 스크립트, roads_box.json(도로 원본 일부)
tests/                     가짜 구글 지도(gmock.js)로 도는 브라우저 테스트
```

```bash
npm install          # d3-geo, topojson, world-atlas, playwright
npm run data         # 지점·코스·도로망 → src/data/gdata.json
npm run pois         # 관광지 조사 원본 → src/data/pois.json
npm run build        # src → index.html
npm test             # 브라우저 테스트 (CHROMIUM_PATH로 크로미움 경로 지정 가능)
```

## 데이터 출처

- 도로망: [Natural Earth](https://www.naturalearthdata.com/) 10m roads(퍼블릭 도메인)에서 오만·UAE 부분만 잘라 `tools/roads_box.json`으로 두고, 빠진 길 몇 개(쿠리야트–수르 해안도로, 수르–라스 알 진즈, 제벨 아크다르)를 손으로 보탰어요. 구글 경로를 못 받을 때만 쓰는 예비 계산용이에요.
- 국경선: [world-atlas](https://github.com/topojson/world-atlas) (Natural Earth).
- 관광지: 2026년 10월에 오만 관광청([experienceoman.om](https://experienceoman.om)), 위키백과, OpenStreetMap(Mapcarta) 등을 보고 정리했어요. 항목별 출처는 `src/data/pois.json`의 `src`에 있어요. 운영시간·요금은 바뀔 수 있으니 가기 전에 다시 확인하세요.
