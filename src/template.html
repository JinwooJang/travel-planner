구글 지도 API 키 넣기

이 파일은 내 구글 키로 위성지도를 띄우고 실제 도로 경로를 계산해요. 한 번만 넣으면 이 브라우저에 저장돼요.

  1. 구글 클라우드 콘솔에서 프로젝트를 만들고 결제 계정을 연결해요.
  2. Maps JavaScript API와 Routes API를 사용 설정해요. 지도에서 리조트·식당 같은 장소를 눌러 이름을 받아 오려면 Places API (New)도 켜요.
  3. 사용자 인증 정보에서 API 키를 만들고, API 제한을 위 API들로 걸어요. 할당량(하루 사용량) 상한과 예산 알림도 걸어 두세요.

키는 이 컴퓨터의 이 브라우저에만 저장되고 다른 곳으로 보내지 않아요. 이 파일을 다른 사람에게 보내도 키는 같이 가지 않아요.
